# TABULARIUM

**From Data to Knowledge.**

Platform sumber terbuka untuk mengelola, memvalidasi, menganalisis, dan mempertukarkan data,
dirancang terutama untuk aparatur dan organisasi pemerintahan (Statistik Sektoral dan Satu Data
Indonesia), tetap umum dan lintas sektor.

> Status: **Tahap 0 (Discovery & Spike)**. Belum ada aplikasi yang dapat dipakai.

## Pendekatan
Desktop-first · Local-first · Modular monolith · Rust core + Python sidecar · AGPL-3.0

## Dokumen
- Dokumen induk: lihat folder `docs/` (versi saat ini: v2.1 draft)
- Keputusan arsitektur: `docs/adr/`
- Spesifikasi: `docs/spec/`
- Rujukan regulasi: `docs/normative/`
- Panduan untuk asisten AI: `AGENTS.md`

## Data
Seluruh data di repository ini adalah **data sintetis** (lihat `examples/`). Jangan pernah commit data nyata.
